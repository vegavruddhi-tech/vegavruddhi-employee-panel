# 📱 Vegavruddhi FSE Mobile Application (`employee-app`)

The dedicated mobile-first React frontend application inside `vegavruddhi-employee-panel` designed specifically for **Field Sales Executives (FSEs)**.

---

## 🎯 Purpose & Scope
This app provides field agents with a fast, responsive mobile interface to register merchants, log daily tasks, view application statuses, and track personal salary incentives on the go.

---
